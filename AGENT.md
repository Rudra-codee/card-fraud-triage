# AGENTS.md

## Goal

Write simple, beginner-friendly machine learning code that is easy to understand, debug, and explain in a college viva.

## Rules

- Prefer simple code over complex or advanced implementations.
- Use basic Python, Pandas, NumPy, and Scikit-learn.
- Use meaningful variable names and short comments.
- Avoid unnecessary classes, abstractions, functions, and libraries.
- Explain important steps in simple English.
- Make only necessary changes to existing code.
- Keep the project structure simple.
- Never sacrifice correctness for shorter code.

## Final Instruction

**Write code as if teaching a student who knows  Python and is learning machine learning. Every important line should be easy to understand and explain. Always prioritize simplicity, readability, and correctness.**
